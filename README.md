Budget Studio
Personal Finance & Budgeting App — Beta v1.0

Budget Studio is a personal finance and budgeting application designed to help users track their spending, manage budgets, and understand their monthly cash flow in one place.

⚠️ Beta v1.0

Budget Studio is currently in its first public beta release. Some features are still under development, and users may encounter bugs, incomplete functionality, or design changes as the application evolves.

✨ Features
💰 Budget Management
Set a monthly spending budget
Define category-level budget limits
Track spending against your budget
View remaining budget
📊 Transaction Tracking
Add income and expenses
Edit existing transactions
Delete transactions
Categorize transactions
View transactions by month
📈 Cash Flow Overview
Monitor income and expenses
Understand monthly cash flow
View spending patterns
Track your financial progress
☁️ Cloud Account & Sync
Account-based access
Cloud synchronization
Pull financial data when signing into an account
Sync status indicators
📱 Responsive Experience
Designed with a mobile-first approach
Responsive layout for different screen sizes
Mobile navigation dock
Clean and minimal interface
🧪 Beta v1.0

This release represents the first public beta version of Budget Studio.

Validate the core budgeting experience
Test transaction management
Test budget tracking
Gather user feedback
Identify bugs and usability issues
Prepare the foundation for future releases
Known Beta Limitations

Bugs or unexpected behavior
Features that are still being refined
UI/UX changes between releases
Temporary synchronization issues
Missing features that may be introduced in future versions

Your feedback is extremely valuable during this stage.

Budget Studio is built using:

React Native

JavaScript/TypeScript-based components

🚀 Getting Started
Prerequisites

Make sure you have the following installed:

Node.js
npm
Expo CLI / Expo tooling
A supported Android or iOS environment
Installation

Clone the repository:

git clone <repository-url>

Navigate into the project:

cd budget-studio

Install dependencies:

npm install
Start the development server
npx expo start

You can then open the application using:

Expo Go
Android emulator
iOS simulator
Development build
🔍 Development Commands

Run the linter:

npx expo lint

Run TypeScript type checking:

npx tsc --noEmit

Check the project for dependency/configuration issues:

npx expo-doctor

🔐 Privacy & Financial Data

Budget Studio is intended to help users manage their personal budgeting information.

Do not enter sensitive information such as:

Bank passwords
Credit/debit card numbers
CVV numbers
OTPs
Banking credentials
Other highly sensitive financial authentication information

Only enter information that is appropriate for the application's budgeting functionality.
